# Changelog

## 1.0.0

首个可用版本。

- 本地 HTTP 桥接服务（TcpListener，仅监听 127.0.0.1，独占端口，令牌鉴权）
- 主线程调度器：socket 线程不直接触碰 Unity API，全部命令回到主线程执行
- 命令模块：系统 / 场景 / 物体 / 组件 / 编辑器 / 日志 / 截图 / 资源 / 游戏构建 / 动态 C#
- `cs.execute`：把 C# 代码写入临时编辑器脚本，编译并执行后回传结果，脚本自动清理
- 编辑器控制面板：端口、令牌、启停、设置、实时日志、自检
- 客户端：`unityctl.ps1`（无依赖）与 `unityctl.py`（仅标准库），支持 `--wait` 自动轮询任务
- 工具：安装到已有工程、新建工程、对运行中的 Unity 做冒烟测试
- 在 Unity 2022.3.62f3c1 上完成编译与端到端冒烟验证
